📖 About The Project
---
The **Food Delivery Website is a fully responsive** and feature-rich web application built using **React.js and styled with Tailwind CSS**. This project simulates a modern food-ordering platform where users can browse **menus, filter dishes, manage their cart**, and place orders seamlessly—just like popular food delivery apps.
Throughout the development of this project, essential React concepts such as **components, state management, props, routing and Redux Toolki**t were implemented to ensure scalable and maintainable code. **The UI is interactive, clean, and optimized for all devices**, making the user experience smooth and intuitive.


<hr/>

✨ Key Features
---

-  🍔 Interactive Food Menu 
-  🗂️ Category-Based Filtering
-  🔍 Real-Time Search Bar
-  🛒 Smart Cart Management
-  💳 Price & Quantity Calculator
-  ⚙️ Redux Toolkit Integration
-  📱 Fully Responsive UI
-  🔔 Toast Notifications
-  🚀 Fast Deployment on Netlify

📂 Key Folders & Files
---
- **/components** – Contains all reusable UI components like Nav, Hero Section, and Cards.
- **/pages** – Includes the main page components such as Home.jsx.
- **/context** – Manages shared state using React Context API.
- **/redux** – Handles global state management using Redux Toolkit (store & cart slice).
- **/assets** – Stores all images used in the website.
- **App.jsx** – Main application component where all sections are rendered.
- **main.jsx** – Entry point of the React app.

<hr/>

🏗️ Architecture
---
The system follows the **simple client-server architecture**
- **Frontend (React + Tailwind):** Handles UI, state, and interactions.
- **Backend API (Local JSON Server at :3000):** Stores and retrieves the data.
 
<hr/>

🛠 Built With
---

- **Frontend**: React 18, vite 5, TailwindCSS 3
- **State Management**: Redux Toolkit
- **Styling**: TailwindCSS 3

⚙️ Getting Started
---

### **Prerequisites**

- Node.js 18+
- npm / yarn / pnpm
- Local API server running at `http://localhost:3000`

---

### **Installation**

```bash
git clone https://github.com/Umesh590/Food-delivery-website.git
cd Food-delivery-website
npm install
```
<hr/>
 
### **Run** 
```
npm run dev
```
Visit:
```
http://localhost:5173
```
Backend API should be running at:
```
http://localhost:3000
```
